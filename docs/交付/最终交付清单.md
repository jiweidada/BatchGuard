## 3. 功能与安全边界

- CLI 和 GUI 均支持单目录只读重复文件扫描。
- 递归发现普通文件，不跟随目录符号链接或 Windows junction。
- 先按文件大小筛选，再以 Windows CNG SHA-256 分块计算内容指纹。
- 支持 1 至 64 个有界哈希工作线程。
- GUI 支持后台扫描、四阶段进度、安全取消、结果主从表和失败详情。
- GUI 面板显示简化日志，CLI 及父终端显示完整结构化日志。
- 日志不记录输入目录或文件完整路径，不写日志文件。
- 不删除、移动、重命名或修改被扫描文件。

## 7. 已知限制

- 仅正式支持 Windows x64。
- 不提供删除、移动、重命名、报告导出、历史记录或实时监控。
- SHA-256 后不执行逐字节二次比较。
- 理论可节省空间是逻辑大小估算，不考虑硬链接、稀疏文件或文件系统压缩。
- 网络盘和机械硬盘的最佳线程数取决于实际环境。
- Qt 5.14.2 已是归档版本，后续长期维护应单独评估 Qt 6。
