## 3. 功能范围

- Windows 宽字符命令行参数。
- 输入目录验证。
- 递归普通文件发现。
- 文件大小候选筛选。
- Windows CNG SHA-256。
- 跨目录重复文件分组。
- 稳定排序的中文扫描报告。
- 发现、元数据和哈希失败隔离。
- 控制台动态扫描进度。
- 有界文件级并发和 `--hash-workers 1-64`。
- 明确退出码 `0`、`1`、`2`、`3`。

MVP M-01 至 M-11 的覆盖矩阵见 `docs/测试/阶段6测试.md`。

## 4. 安全边界

- 程序只读取输入目录。
- 不删除、移动、重命名或修改文件。
- 不跟随目录符号链接或 Windows junction。
- 不读取唯一大小文件的内容。
- 单文件失败不会中断整个扫描。
- 项目不包含凭据、公司代码、模型、图片或业务测试数据。

## 7. 已知限制

- 仅正式支持 Windows。
- 不提供删除、移动、报告导出、历史记录、实时监控、取消或 GUI。
- SHA-256 之后不执行逐字节二次比较，这是 v0.1 已接受的产品取舍。
- 网络盘和机械硬盘的最佳线程数取决于实际环境，线程数更高不一定更快。
- 动态进度只在标准输出连接真实控制台时启用。
