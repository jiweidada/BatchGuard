## 当前已确定

- 项目使用 C++20。
- 已完成纯 C++ 核心、CLI、扫描进度和有界文件级并发。
- 使用 Windows CNG SHA-256，不新增密码学第三方依赖。
- v0.2.0 计划增加 Qt Widgets 图形界面和安全取消。
- v0.2.0 仍保持只读，不增加删除、移动、重命名和报告导出。
- GUI 使用薄视图、单一控制器、后台工作对象和只读结果模型。
- 扫描结果采用“结论摘要、主要指标、重复组主表、所选组路径详情和失败项”的
  渐进展示结构。
- 理论可节省空间只作为逻辑大小估算，并明确说明硬链接、稀疏文件和压缩限制。
- 首先验证本机 Qt 5.14.2 `msvc2017_64` 与当前工具链的兼容性。
- 采用小步结对开发：每次只实现一个可审查增量。
- 不复制任何公司代码、图片、模型或业务数据。

## 协作约定

1. 每个增量开始前先说明目标、文件范围和验收方式。
2. 单次尽量只改 1～3 个文件。
3. 改动完成后先展示 diff、构建结果和设计理由。
4. 由基哥检查并明确回复“继续”后，再进入下一个增量。
5. 未经确认不自动提交 Git，也不扩展计划外功能。
