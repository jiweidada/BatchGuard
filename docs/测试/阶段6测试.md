## 1. 测试目标

阶段 6 不新增产品功能，重点验证阶段 1 至阶段 5 的组合行为和健壮性：

- M-01 至 M-11 均有可重复执行的自动化测试。
- 较多同大小候选能够完成哈希和重复分组。
- 对未变化目录重复扫描得到完全稳定的报告。
- 扫描不修改文件内容或最后写入时间。
- 文件在发现后消失时记录 `Metadata` 失败，并继续处理其他文件。
- 文件被独占锁定时显示非空错误原因，并返回 `2`。
- Debug 和 Release 全量测试结果一致。
- 测试数据全部在运行时生成并通过 RAII 清理。

## 4. 阶段 6 新增自动化测试

| 编号 | 场景 | 预期 |
|---|---|---|
| S6-01 | 60 对、共 120 个同大小候选文件 | 成功处理 120 个文件并建立 60 个双成员重复组 |
| S6-02 | 同一目录连续扫描两次 | 汇总、摘要、成员路径完全相同 |
| S6-03 | 连续扫描后检查输入文件 | 内容与最后写入时间保持不变 |
| S6-04 | 文件发现后、元数据读取前删除一个文件 | 记录 `Metadata`，另一个文件继续处理 |
| S6-05 | 同一目录连续运行两次 CLI | 中文报告文本和退出码完全一致 |
| S6-06 | 独占锁定候选文件 | 报告包含非空错误原因并返回 `2` |

大批量用例的所有内容长度相同，使 120 个文件都进入 SHA-256 候选阶段；每对文件
内容相同，不同对之间内容不同，从而同时验证候选编排和多重复组分离。

## 7. 实际结果

2026-07-29 完成 Debug 和 Release 验收：

- Debug 配置和构建成功，没有新增编译警告。
- Release 配置和构建成功，没有新增编译警告。
- Debug CTest 发现 53 个测试，0 个失败，总耗时 0.36 秒。

  链接权限而标记为 Skipped，不计为产品失败。
- M-01 至 M-11 均已映射到明确的自动化测试。
- 120 个同大小候选文件全部成功处理，形成 60 个正确的双成员重复组。
