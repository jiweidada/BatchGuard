## 1. 测试目标

验证阶段 2 满足以下条件：

- `BatchGuard <目录路径>` 接受一个有效目录。
- `--help` 和 `--version` 能够独立使用。
- 参数缺失、目录不存在、普通文件和非法参数返回 `1`。
- 帮助、版本和有效目录返回 `0`。
- Windows 中文路径和带空格路径能够完整传入核心层。
- 输入验证位于核心库，CLI 只负责参数和展示。
- 阶段 2 不遍历目录、不读取或修改用户文件。

## 3. 功能实现位置与调用链

### 3.1 总体调用流程

```text
BatchGuard.exe
    ↓
apps/cli/main.cpp：wmain 接收 Windows 宽字符参数
    ↓
apps/cli/cli_app.cpp：runCli 解析参数并决定操作
    ↓
src/core/input_validator.cpp：validateInputDirectory 验证目录
    ↓
apps/cli/cli_app.cpp：生成正常提示、错误提示和退出码
    ↓
apps/cli/main.cpp：转换为 UTF-8 并写入控制台
```

`main.cpp` 只处理程序边界、对象组装和异常兜底，不包含参数判断和目录验证业务。

### 3.2 文件职责

| 文件 | 主要职责 |
|---|---|
| `CMakeLists.txt` | 定义核心库、CLI 应用层、可执行程序及依赖关系 |
| `apps/cli/main.cpp` | 使用 `wmain` 接收 Unicode 参数，调用 CLI 流程并返回退出码 |
| `apps/cli/cli_app.h` | 声明 CLI 退出码和 `runCli` 接口 |
| `apps/cli/cli_app.cpp` | 处理参数数量、帮助、版本、未知选项、提示文本和退出码 |
| `apps/cli/console_encoding.h` | 声明 Windows 控制台编码接口 |
| `apps/cli/console_encoding.cpp` | 将 UTF-16 文本转换为 UTF-8 并写入输出流 |
| `include/batchguard/core/input_validator.h` | 声明输入验证错误、结果和公共验证接口 |
| `src/core/input_validator.cpp` | 使用 `std::filesystem` 和 `std::error_code` 验证路径 |
| `tests/test_support/temporary_directory.h` | 提供自动清理的 RAII 临时测试目录 |
| `tests/unit/cli_app_test.cpp` | 测试 CLI 参数、输出、退出码和 UTF-8 转换 |
| `tests/unit/input_validator_test.cpp` | 直接测试核心目录验证，不依赖完整 CLI |
| `tests/stage1/smoke_test.cpp` | 保留阶段 1 的 C++20 和测试接线验证 |
| `tests/CMakeLists.txt` | 构建 `batchguard_tests` 并让 CTest 自动发现 GTest 用例 |

### 3.3 各项功能的实现位置

| 功能 | 实现位置 | 实现方式 |
|---|---|---|
| 缺少参数 | `runCli` | 参数列表为空时输出原因并返回 `1` |
| 多个参数 | `runCli` | 参数数量大于一个时返回 `1` |
| `--help` | `printUsage`、`runCli` | 输出使用方式并返回 `0` |
| `--version` | `runCli` | 输出 CMake 提供的项目版本并返回 `0` |
| 未支持的选项 | `runCli` | 拒绝其他 `--` 开头的选项并返回 `1` |
| 空路径 | `validateInputDirectory` | 返回 `InputValidationError::EmptyPath` |
| 目录不存在 | `validateInputDirectory` | 使用 `std::filesystem::exists` 检查 |
| 输入为普通文件 | `validateInputDirectory` | 使用 `std::filesystem::is_directory` 检查 |
| 无法访问路径 | `validateInputDirectory` | 保存 `std::error_code` 并返回 `CannotAccess` |
| 有效目录 | `validateInputDirectory`、`runCli` | 验证成功并返回 `0`，不扫描目录内容 |
| 中文路径输入 | `wmain` | 使用宽字符参数，避免传统代码页的有损转换 |
| 中文控制台输出 | `console_encoding.cpp` | 使用 Windows API 转换并输出 UTF-8 |
| 内部异常 | `wmain` | 在应用边界统一捕获并返回 `3` |

### 3.4 头文件与实现文件的关系

公共头文件只声明调用方需要的类型和函数，实现细节保存在 `.cpp` 文件中：

```text
input_validator.h ──声明──> InputValidationError
                           InputValidationResult
                           validateInputDirectory

input_validator.cpp ─实现──> validateInputDirectory

cli_app.h ──────────声明──> ExitCode
                           runCli

cli_app.cpp ────────实现──> 参数解析、帮助、版本、错误提示和退出码
```
