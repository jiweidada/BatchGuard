# 阶段 16 测试记录

> 日期：2026-07-30
>
> 配置：CLion `cmake-build-debug`，Qt GUI 开启
>
> 结论：结构化日志、终端完整输出和 GUI 简化日志面板通过 Debug 验证。

## 1. 测试范围

阶段 16 验证以下行为：

- 日志统一采用“时间：信息类型：所属层：信息内容”的单行 UTF-8 格式。
- 信息类型稳定映射为 `DEBUG`、`INFO`、`WARN` 和 `ERROR`。
- 时间包含毫秒和本地时区偏移。
- 摘要和字段中的回车、换行、Tab 不会破坏单行记录。
- `TerminalLogSink` 并发写入时不会把多条记录穿插到同一行。
- CLI 完整日志写入标准错误流，原扫描报告仍写入标准输出。
- GUI 与终端消费同一条结构化记录。
- GUI 面板过滤 `DEBUG`，隐藏完整附加字段并最多保留最近 500 条。
- GUI 日志信号只在 GUI 控制器线程消费。
- 开始、阶段变化、阶段完成、取消、完成和失败日志在对应边界产生。
- 日志不包含输入目录或文件完整路径。
- GUI 目标保持 `WIN32`；只有存在父控制台时才连接，不额外创建控制台。

本阶段不验证日志文件、导出、搜索或复杂过滤，因为这些能力不在阶段范围内。

测试数据全部在临时目录中运行时生成，没有使用固定盘符或真实业务数据。

## 3. 执行命令

加载 MSVC 环境后构建现有 Debug 目录：

```powershell
cmake --build cmake-build-debug
```

运行日志和 GUI 定向测试：

```powershell
ctest --test-dir cmake-build-debug --output-on-failure `
    -R "LoggingTest|CliAppTest.EmitsStructuredLogsWithoutSensitiveDirectoryPath|BatchGuardGuiTests"
```

运行 Debug 全量回归：

```powershell
ctest --test-dir cmake-build-debug --output-on-failure
```

重复运行并发终端日志和 GUI 测试：

```powershell
ctest --test-dir cmake-build-debug --output-on-failure `
    --repeat until-fail:20 `
    -R "BatchGuardGuiTests|LoggingTest.TerminalSinkKeepsConcurrentRecordsOnSeparateLines"
```

验证真实 CLI 入口：

```powershell
.\cmake-build-debug\BatchGuard.exe --version
```

## 5. 安全与架构结论

- `batchguard_logging` 使用标准 C++20，不依赖 Qt 或第三方日志库。
- `batchguard_core` 不依赖日志输出设施，核心业务和展示边界保持单向依赖。
- 日志只记录扫描编号、线程数、数量、字节、耗时、状态和错误类别。
- 路径脱敏测试确认完整格式化文本不包含测试输入目录标识。
- GUI 只展示简化状态；完整附加字段只发往父终端。
- 日志只在进程运行期间输出，不写入磁盘。
